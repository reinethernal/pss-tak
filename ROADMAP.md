# Roadmap ПСР / SAR

Приоритеты расширения системы на [fts.plasmadancer.ru](https://fts.plasmadancer.ru)  
по публичным практикам поисково-спасательных работ (МЧС РФ / волонтёры, LKP–POA–POD, IAMSAR-роли, типовой функционал SAR-ПО).

Связанный документ для пользователей: [FEATURES.md](FEATURES.md).

---

## Сделано / в работе

| Функция | Статус |
|---------|--------|
| Фото/улика на точке (ATAK Quick Pic) | Есть в ATAK CIV |
| Фото-метка PSS TAK → Marti `b-i-x-i` + fileshare | Клиент v0.40.1+ |
| Приём фото-метки в PSS TAK (превью) | Клиент v0.40.1+ |
| Превью фото у маркера на веб-карте OTS | Патч сервера (слетает при апдейте OTS) |
| Типы точек ПСР (русские подписи UI) | PSS TAK v0.42.0+; фильтры на веб-карте (RU) |
| Секторы поиска на основной карте | Draw/список/CRUD на `/map`; API; CoT `u-d-f` |
| Задание группе | Операция: `/downloads/psr-operation.html` + API; карточка в PSS TAK Mission Sync |
| Учёт состава выезда | Та же страница операции + API; read-only в PSS TAK |
| Ориентировка пропавшего | Карточка субъекта + фото в mission; PSS TAK v0.43+ |

> **Почему патчи слетают при апгрейде OTS:** официальный updater делает `pip install -U` (перезапись `site-packages/opentakserver/`) и `rm -fr /var/www/html/opentakserver/*` + extract UI. Postgres и `~/ots/config.yml` не трогаются.  
> **Восстановление:** [`packages/ots-overlay/`](packages/ots-overlay/) — `apply-psr-ots-overlay.sh` после апгрейда, затем `systemctl restart opentakserver cot_parser`. Перед коммитом патчей: `sync-from-live.sh`.

## B1 — высокий приоритет (дыры полевого штаба)

| Функция | Зачем | Куда |
|---------|-------|------|
| **Фото/улика на точке** | Находка на карте, не только в чате | PSS TAK + веб *(сделано)* |
| **Типы точек ПСР** | LKP / PLS / IPP / «проверено» / «опасность» / «сборка» | PSS TAK + веб-фильтры *(сделано)* |
| **Секторы поиска (полигоны)** | Разбивка района, назначение группе | Основная карта `/map` *(сделано)* |
| **Задание группе** | Tasking: сектор, срок возврата, маршрут | Операция + Mission Sync *(сделано)* |
| **Учёт состава выезда** | Кто прибыл, телефон, транспорт, навыки | Операция + Mission Sync *(сделано)* |
| **Ориентировка пропавшего** | Фото и приметы всем группам | Карточка субъекта + файл в mission *(сделано)* |

**Следующий инкремент (рекомендация):** треки / «пройдено» (B2).

## B2 — средний приоритет

| Функция | Зачем | Куда |
|---------|-------|------|
| **Треки / «пройдено»** | Покрытие сектора, разбор после смены | Клиент breadcrumb → слой треков |
| **Смена / операционный период** | Суточный handoff | Веб снимок операции + отчёт |
| **Контрольный срок возврата** | Безопасность поисковиков | Таймер у задания + тревога штабу |
| **Офлайн-очередь** | Лес без сети: метки/фото уходят при связи | PSS TAK local queue |
| **Печать/экспорт карты** | Сетка квадратов, GPX | Веб GPX/KML секторов и точек |
| **Журнал решений штаба** | Не путать с полевым чатом | Отдельная лента в операции |
