# Что умеет система ПСР

Для людей в поле и в штабе.  
Адрес: **https://fts.plasmadancer.ru**

Простыми словами: это **общая карта и общий штаб** для поиска и спасения. Все видят одно и то же — кто где, что уже проверено, куда идти дальше.

---

## Зачем это нужно

Без такой системы обычно так:

- позиции в голове или в разных чатах;
- фото разбросаны по телефонам;
- штаб не уверен, кто уже прошёл участок;
- «кто последний видел пропавшего» выясняют голосом по кругу.

С ПСР:

- штаб смотрит карту в браузере;
- полевые идут с телефоном;
- метки, фото и сообщения собираются в одном месте.

---

## Кто чем пользуется

| Кто | Чем |
|-----|-----|
| Штаб / командир | Сайт в браузере (`/map`, `/downloads/psr-operation.html`) |
| Поисковики, кинологи, медики, водители, БПЛА | **ПСР TAK** (основной полевой клиент) |
| Старший группы / полевой КП | **ПСР TAK** в режиме «Старший» или «Полевой штаб» |
| Наблюдатель / стажёр | ПСР TAK read-only / `MISSION_READ_ONLY` |
| Опытный оператор / спец. плагины | **ATAK CIV** (опция, не обязателен) |
| Кому нужно показать видео с места | **ПСР Видео** (или кнопка «Стрим» из ПСР TAK) |
| Семья / свидетель без приложения | Пока нет (SMS-гео — B4) |

## Что система умеет (просто)

**Видеть людей на карте**  
Телефон сам отмечает, где вы. Штаб и другие группы это видят.

**Ставить точки**  
«Здесь нашли вещь», «сюда не ходить», «последнее известное место», «точка сбора».

**Вести выход как «операцию»**  
Отдельная папка события: описание, кто допущен, файлы, точки, переписка по этому выезду.

**Кидать фото и файлы**  
Сняли у ручья / у подъезда — отправили. Штаб открывает в разделе файлов или внутри операции.

**Подать тревогу**  
Если нужна срочная помощь или пропал контакт — это не обычная метка, а отдельный сигнал.

**Учесть эвакуацию**  
Если человека везут / несут с места — отдельный раздел, чтобы не путать с поиском.

**Показать живое видео**  
Камера телефона (или экран) → штаб смотрит онлайн. Потом можно открыть запись ещё какое-то время.

**Разделить доступ**  
Кинологи видят своё, штаб — всё нужное, посторонние группу не видят. Если операция «не появилась» на телефоне — чаще всего просто нет доступа, попросите штаб добавить.

## Какое приложение поставить

| Нужно | Ставьте |
|-------|---------|
| Полевая работа ПСР (карта, метки, фото/голос, чат, задания) | **ПСР TAK** (+ персональная ссылка штаба) |
| Спец. плагины ATAK / привычный CIV | **ATAK CIV** + zip настроек ПСР (опция) |
| Транслировать видео | **ПСР Видео** (отдельное приложение) |

### Режимы ПСР TAK (прогрессивное раскрытие)

В **Настройки → Режим поля** выберите роль. Меню карты и вкладка «Выезд» показывают только нужные действия.

| Режим | Для кого | Что доступно |
|-------|----------|--------------|
| **Поисковик** | 80% волонтёров | Позиция, точки ПСР, фото/голос, чат, тревога, своё задание (Принять / Готово), треки, ориентировка |
| **Старший группы** | Старший на участке | + задания группы, статус сектора «пройден», чек-ин состава, линия/полигон маршрута |
| **Полевой штаб** | Планшет у КП | + список секторов, создать задание, нарисовать сектор → сервер, состав, слои AIS/ADS-B, ссылка GPX |

Планирование POA, авто-сетка, журнал решений и печать карты — **только веб** (`/map`, `psr-operation.html`).

## Фото на карте (геометка с фото)

Находку (вещь, след, объявление) лучше сразу **привязать к точке на карте**, а не кидать фото в общий чат без координат.

### В ATAK CIV (уже есть)

1. На карте: **Quick Pic** (быстрое фото) — снимок становится точкой типа «фото» на вашей позиции / выбранном месте.  
2. Или: поставить точку → **вложения (Attachments)** → добавить фото → отправить / Mission Package.  
3. Файл уходит на сервер (Marti); другие ATAK и штаб видят точку; файл — в «Файлы» / операции.

### В PSS TAK (с v0.40.1)

Долгое нажатие на карте → **Photo Marker** → камера или галерея.  
Точка уходит на сервер вместе с фото (совместимо с ATAK Quick Pic / `b-i-x-i`).  
По чужой фото-точке: тап → превью (скачивается с Marti).

План дальнейшего расширения (задания группам, учёт состава): [ROADMAP.md](ROADMAP.md).

### В OpenTAK ICU

Только стрим видео. Фото-метки там нет — для улик используйте ATAK или PSS TAK.

### На веб-карте штаба

Если у точки есть фото (fileshare / hash) — в карточке маркера показывается превью.  
Иначе файл остаётся только в разделе «Файлы».

## Типы точек ПСР (единый язык)

| Код (провод) | Callsign | Подпись в UI |
|--------------|----------|--------------|
| `psr:lkp` | LKP | Последнее известное |
| `psr:pls` | PLS | Где видели |
| `psr:ipp` | IPP | Старт планирования |
| `psr:checked` | CHECKED | Проверено |
| `psr:danger` | DANGER | Опасность |
| `psr:rally` | RALLY | Сборка |

**PSS TAK (с v0.42):** Tools → «ПСР точки» или долгое нажатие → **Точка ПСР**.  
На проводе callsign и `psr:…` без изменений — на карте и в палитре русские названия.  
Штаб фильтрует на веб-карте кнопками с русскими подписями.

**ATAK:** те же callsign вручную или пресеты; в remarks — `psr:…` или callsign из таблицы.

## Секторы поиска

Штаб рисует и правит сектора **на основной карте** (`/map`, нужен вход):

1. Панель секторов → полигон (Leaflet.Draw) → имя / назначено / операция / статус.  
2. Список: клик → fitBounds; «Изменить / Пройден / Удалить».  
3. Сектор уходит клиентам как drawing CoT (`u-d-f`).

Старый URL `/downloads/psr-sectors.html` перенаправляет на `/map`.

В **PSS TAK:** сектор виден как drawing; свой полигон (Tools → Drawing → polygon) тоже рассылается на сервер.

## Задания и состав выезда

Карточка операции: [psr-operation.html](https://fts.plasmadancer.ru/downloads/psr-operation.html)?mission=ИМЯ

- **Ориентировка** — ФИО, приметы, одежда, медицина, где/когда видели, фото; статус активна/найден/снята. Одна активная на операцию.  
- **Задания** — создать (заголовок, текст, кому, сектор, срок возврата), статусы, просрочка по сроку; запись в лог операции.  
- **Состав** — ФИО/позывной, телефон, транспорт, навыки, роль, статус прибытия; кнопка «подтянуть из онлайн EUD».

В **PSS TAK (v0.48+):** вкладка **Выезд** (Mission Sync) → тап по миссии → ориентировка, задания с кнопками **Принять / Готово**, состав с **Чек-ин** (по режиму роли). Создание задания — в режиме «Полевой штаб».

## Треки / покрытие

На штабной карте `/map` (панель справа):

1. Включите **Треки**, выберите окно (1 / 6 / 24 ч или «смена с…»).  
2. Полилинии по истории GPS с сервера (`/api/tracks`); цвет по позывному.  
3. Статус сектора **Пройден** по-прежнему вручную — треки только показывают покрытие.  
4. **Экспорт KML** — ссылка на Marti ExportMissionKML для ATAK/архива.

В **PSS TAK (v0.48+):** Layers → **Треки** — локальный breadcrumb + подгрузка истории группы с `/api/tracks` (окно ~6 ч).

## Смена / операционный период

На странице операции `/downloads/psr-operation.html` → вкладка **Смена**:

1. **Открыть смену** — название, командир, кто принимает. Одновременно только одна открытая смена на операцию.  
2. **Снимок сейчас** — превью счётчиков (секторы, задания, состав, треки, ориентировка) без записи.  
3. При закрытии заполните итог / находки / приоритеты следующей смены → **Закрыть и зафиксировать снимок**.  
4. **Отчёт** — текстовый handoff в новой вкладке; **Копировать отчёт** — в буфер.  
5. **Треки на карте** → `/map`: выставьте окно треков по времени начала смены.

Статус сектора «пройден» и треки живут отдельно; смена фиксирует состояние на момент закрытия. PDF и PSS TAK в v1 нет.

## Контрольный срок возврата

При создании задания укажите **срок возврата** (`datetime`).

1. В карточке задания — **таймер** (осталось / просрочено).  
2. За 30 минут — предупреждение (жёлтый баннер на странице операции и на `/map`).  
3. После срока статус становится **просрочено**, в лог операции пишется `psr:due`, socket `mission_task_due`.  
4. Скан раз в минуту на сервере + при каждом запросе списка заданий.

Закройте просрочку кнопкой **выполнено**, когда группа вернулась.

## Офлайн-очередь (PSS TAK v0.45+)

В лесу без связи метка и фото-метка остаются на карте телефона и кладутся в **очередь на отправку**.

1. Поставьте точку / фото как обычно — увидите «queued / will send when online».  
2. Когда телефон снова подключится к серверу ПСР, очередь уходит сама (CoT + upload фото в Marti).  
3. PPLI (своя позиция) в очередь не пишется — только операторские метки и фото.

## Экспорт секторов (GPX / KML)

На карте `/map` откройте кнопку **ПСР** (справа внизу) → блок **Экспорт**:

- **GPX секторов** — `/api/search_sectors/export.gpx`  
- **KML секторов** — `/api/search_sectors/export.kml`  
- Опционально `?mission=ИМЯ` — только сектора этой операции.  
- **KML миссии** — Marti ExportMissionKML по выбранному треку/uid.

## Журнал решений штаба

На странице операции → вкладка **Журнал**:

1. Выберите тип: решение / брифинг / безопасность / прочее.  
2. Введите текст → **Записать**.  
3. Полный текст хранится в журнале штаба; в лог операции уходит короткая пометка `psr:decision`.  
4. Записи за смену попадают в отчёт при закрытии смены.

Это не полевой чат миссии — только штабные решения.

## Авто-сетка секторов

На `/map` → панель **ПСР** → блок **Авто-сетка**:

1. Нарисуйте **прямоугольник** (оранжевый инструмент Draw) или нажмите **По видимой карте**.  
2. Выберите размер ячейки (250 / 500 / 1000 м), префикс имён (`Кв-`), операцию.  
3. **Создать сетку** — сервер создаёт сектора `Кв-A1…` (лимит ≤ 80) и CoT `u-d-f`.

API: `POST /api/search_sectors/grid` (`bbox`, `cell_m`, `mission_name`, `name_prefix`, `max_cells`).

## POA / POD (план штаба)

Эвристика штаба, **не** научный Lost Person Behavior.

1. В ориентировке укажите **категорию** и **мобильность** (шаблон весов).  
2. Операция → вкладка **POA**: веса по секторам (сумма ≈ 100%), заметки, «равномерно».  
3. **Пройден → перераспределить** — обнуляет сектор и делит остаток между активными.  
4. На `/map` полигоны окрашиваются по POA (cyan → orange → red; пройден — серый).

API: `GET/PUT /api/missions/<name>/poa_plan`, `POST …/poa_plan/update_after_clear`.

## Голосовые заметки (PSS TAK v0.46+)

1. Долгое нажатие на карте → радиальное меню → **Голос**.  
2. Разрешите микрофон → **Запись** → **Стоп и отправить**.  
3. CoT тип `b-i-x-a`, файл `voice.m4a` в Marti (как фото `b-i-x-i`).  
4. Без сети — в outbox (`KIND_VOICE`), уйдёт при связи.  
5. Штаб на `/map`: клик по метке → превью `<audio>` / фото (если есть fileshare).

## Воздух и вода (ADS-B / AIS)

### В PSS TAK — Layers («Слои карты»)

| Слой | Что |
|------|-----|
| **Воздух (ADS-B)** | Overlay плагина OpenSky; переключатель реально скрывает самолёты |
| **Суда (AIS)** | Морской CoT с сервера (`a-*-S-…`); скрыть, если мешает |

Включите ADS-B в **Settings → Plugins → ADS-B** (опрос OpenSky вокруг карты).

### На сервере OTS (`~/ots/config.yml`)

| Параметр | Назначение |
|----------|------------|
| `OTS_ADSB_*` / job `get_adsb_data` | Самолёты в группу ADS-B |
| `OTS_AISHUB_USERNAME` + bbox | Суда с AISHub |
| `OTS_AIS_GROUP` (по умолчанию `AIS`) | Группа для AIS CoT (**не** ADS-B) |

Включите scheduled jobs в UI OTS (или config). Клиенты должны быть в группе **AIS** / **ADS-B** (IN), иначе точки не придут.

После апдейта OTS: `apply-psr-ots-overlay.sh` (патч AISHub → `OTS_AIS_GROUP.OUT`).

## Роли ПСР (рекомендуемая модель A)

Доступ сегодня режется тремя механизмами (отдельный IAM по ролям A **не** внедряли — хватает groups + mission role):

| Механизм | Где | Что даёт |
|----------|-----|----------|
| Роль пользователя OTS | Flask-Security | Веб: пользователи, jobs, плагины |
| Группы TAK | Groups IN/OUT | Какие CoT/операции видит EUD |
| Роль в миссии | OWNER / SUBSCRIBER / READ_ONLY | Писать / только читать операцию |
| Роль на выезде | `roster.role_on_op` | Учёт состава (текст) |

### Вариант A — пять полевых ролей (рекомендуется для fts)

| Роль | Клиент | Веб OTS | Функционал |
|------|--------|---------|------------|
| **Админ системы** | — | полный | Пользователи, группы, сертификаты, ADS-B/AIS jobs, overlay |
| **Командир / диспетчер штаба** | ATAK или PSS TAK (опц.) | `/map`, `psr-operation` | Секторы, сетка, задания, состав, ориентировка, смена, журнал, POA, сроки, треки, экспорт, тревоги |
| **Старший группы** | PSS TAK (режим «Старший») | обычно нет | Карта, чат, метки, фото/голос, ack заданий, статус сектора; ATAK — опция |
| **Поисковик / кинолог / медик / БПЛА** | **PSS TAK** (режим «Поисковик») | нет | Позиция, метки, фото/голос, чат операции, слои по группе |
| **Наблюдатель / стажёр** | PSS TAK | read-only по желанию | `MISSION_READ_ONLY`; без записи в боевую операцию |

Соответствие: штаб → веб + OWNER; поле → cert + группы IN + SUBSCRIBER; наблюдатель → READ_ONLY.

**Вариант C (минимум):** штаб (1–2 с веб) + поле (SUBSCRIBER) + админ вне выезда.  
SMS-роль «семья/свидетель» — только после B4.

## Примеры ситуаций

### 1. Пропал человек в лесу

Семья сообщила вечером. Штаб открывает операцию «Лес, кв. …», отмечает на карте последнее известное место.

Группы пеших выходят с телефонами. Каждая видна на карте. Кто прошёл просеку — ставит точку «проверено». Нашли следы — фото в операцию.

Кинологи работают своим цветом на карте, их не путают с пешими. Штаб не орёт в общий чат «где вторая группа» — смотрит карту.

### 2. Поиск в городе по адресам

Нужно обойти дворы и подъезды. Штаб даёт список адресов в описании операции.

Поисковик подошёл к дому → отметил точку → сфотографировал объявление на двери → отправил. Следующий не идёт туда второй раз зря.

### 3. Несколько групп одновременно

Одни в лесу, другие на дорогах, штаб в школе. У всех одна карта.  
Можно две операции: «поиск» и «логистика/штаб» — чтобы служебные сообщения не мешали полевым.

### 4. Человека нашли, нужна помощь

На карте уже ясно, кто ближе. Медики видят точку. В разделе эвакуации фиксируют, что человека вывозят, чтобы остальные не продолжали искать «вхолостую».

### 5. Плохо слышно по рации, но нужно показать, что видишь

У оврага / в подъезде / с коптера. Включают **ICU** — штаб видит картинку и слышит, что происходит, без «опиши словами».

### 6. Новичок в отряде, первый выезд

Штаб шлёт **персональную ссылку**. Волонтёр ставит **PSS TAK**, открывает ссылку → enrollment → на карте операции. Режим по умолчанию — «Поисковик». ATAK не обязателен.

### 7. После выхода — «что было?»

Через день разбирают: где были группы, какие фото, что писали в чате операции, было ли видео. Не нужно собирать скрины из десяти личных переписок.

### 8. Связь то появляется, то пропадает

Пока есть интернет — позиция и сообщения уходят на сервер. Пропал сигнал — на карте человек «замирает» на последней точке. Когда связь вернулась — снова живой.  
Рации и Meshtastic (если есть) — это дополнение, а не замена карты в штабе.

### 9. Тренировка / учение

Та же схема, что на боевом выезде: операция, группы, карта. Можно отработать «тревогу» и «эвакуацию» без путаницы в бытовых мессенджерах.

### 10. Нужен только маячок

Водителю или статисту на точке достаточно **PSS TAK** в режиме «Поисковик»: открыл — на карте штаба. Полный сценарий поиска (метки, фото, задания) — тот же APK без смены приложения.

## Чего ждать не стоит

- Это не замена обычному звонку и не «ещё один WhatsApp».
- Это не волшебная рация: без связи с интернетом телефон не обновит карту у штаба (офлайн-очередь меток — да).
- PSS TAK не клонирует все плагины ATAK; для редких спец. модулей CIV остаётся опцией.

## Персональная ссылка (один человек)

Штаб выдаёт **одну HTTPS-ссылку** волонтёру в мессенджер — без пароля учётки в URL.

1. Веб-UI → **Пользователи** → у нужного логина **«Скопировать ссылку»**  
   (или «Приложения для телефонов» → генератор / [psr-invite-admin.html](https://fts.plasmadancer.ru/downloads/psr-invite-admin.html)).
2. Волонтёр открывает HTTPS-ссылку на телефоне → «Открыть в ПСР TAK» (не сырой tak:// в чате — браузер его часто блокирует) → enrollment; при необходимости truststore/zip/APK.
3. **Пароль корневого сертификата (P12): `atakatak`.**  
   Пароль учётной записи OTS штаб сообщает отдельно (не вшивается в ссылку).

API: `POST /api/psr/invite` (admin), публичная страница `GET /api/psr/invite?t=…` + [psr-invite.html](https://fts.plasmadancer.ru/downloads/psr-invite.html).

В ссылке короткий код (64 hex), не JWT — иначе мессенджеры обрезают URL. Старые длинные ссылки с JWT тоже ещё открываются.

## С чего начать

1. Попросите у штаба **персональную ссылку** (или логин).  
2. Поставьте **ПСР TAK** с F-Droid / сайта / invite-страницы.  
3. Откройте ссылку → enrollment → карта; режим «Поисковик» по умолчанию.  
4. Штаб работает на **https://fts.plasmadancer.ru**.  
5. Для видео — **ПСР Видео** (из ПСР TAK: Ещё → «Открыть стрим»).  
6. ATAK CIV — только если штаб явно просит (спец. плагины).
