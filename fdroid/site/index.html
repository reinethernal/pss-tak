ПСР — свой F-Droid

Раздача полевых Android-клиентов для системы ПСР (OpenTAKServer на fts.plasmadancer.ru). Это не официальный f-droid.org.

Подробнее: README, SOURCES.md.

Приложения в репозитории

  • ПСР TAK (ru.plasmadancer.psr.tak) — новые установки
  • PSR TAK legacy (soy.engindearing.omnitak.mobile) — обновление старого OmniTAK/PSS
  • ПСР Видео (ru.plasmadancer.psr.icu) — новые установки
  • ICU legacy (io.opentakserver.opentakicu.debug) — обновление старого ICU PSR

Если приложение уже стояло — F-Droid обновит тот же package id. Новым — ставьте ru.plasmadancer.*.

Пакет io.opentakserver.opentakicu.debug F-Droid может скрывать (id оканчивается на .debug). Включите в F-Droid: Настройки → Эксперт → показывать debug-версии — либо ставьте APK с сервера штаба.
